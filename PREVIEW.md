# Горница — интерактивный атлас v3

Рабочая версия редизайна размещена отдельно в `explore-v2.html`. Основной `index.html`, SEO, домен, API уведомлений и Vercel rewrites не изменены. Ветка создана от актуального main; исходный концепт PR #3 перенесён и переработан без конфликта с основной веткой.

## Изменения

- Настоящие фотографии из коллекции проекта вместо Мальдив на обложке. Асимметричная сетка, адаптивные карточки, мобильная навигация, подбор в виде фотобилета.
- 30 мест и 15 маршрутов из актуального main. Воспроизводимый экспорт в `scripts/export-explore-data.cjs`; импортирует описания, фото, практические сведения и остановки.
- Нормализованы старые ссылки L-* → ВЛ-*. Связи с маршрутами построены по остановкам, не по ошибочным `routeLink`. Например, Светланская больше не направляет в сафари-парк.
- Поиск с поддержкой е/ё, категории, алфавитная сортировка, постепенная загрузка карточек, избранное и честное пустое состояние.
- Подбор использует один выбранный объект для текста и открытия; переключение перебирает все подходящие места. Есть сценарий с детьми и ограничение на свободный вход по данным коллекции.
- Современные и старые hash-ссылки на кириллические ID, обновление страницы, навигация назад/вперёд; отдельные ссылки на маршруты.
- Нативный modal dialog: изоляция фона, Escape, клавиатура, возврат фокуса, свайп фотографий. Web Share с копированием ссылки и ручным резервным вариантом.
- Исправлен архивный маршрут на Тобизина: убран неверный обход через «океанариум ДВФУ» и обещание последнего автобуса. Добавлен подход через бухту Карпинского по ТИЦ; расчётные ориентиры подписаны.
- Необязательная погода Open-Meteo с таймаутом, проверкой свежести и рабочей ссылкой на прогноз при ошибке.
- Сведения об Орлином гнезде, Токаревской кошке и мысе Тобизина частично сверены с ТИЦ Приморского края 26.10.2026. Объём проверки указан в карточке. Остальные данные явно помечены архивными.
- Предпросмотр закрыт от индексации. Основной сайт и его canonical не менялись.

## Проверки

```sh
node --test tests/explore.test.cjs
node --check explore-app.js
node scripts/build-preview.cjs
```

Девять групп автотестов: полнота данных, разрешение связей, кириллические и некорректные ссылки, отказ/повреждение localStorage, фильтры и поиск, подбор и перебор, экранирование и URL изображений, достоверность статусов источников, корректировка подхода к Тобизина.

Браузерная проверка в Chrome: поиск Тобизина, открытие карточки, переключение фото, сохранение, перезагрузка deep link с сохранённым избранным, Escape, подбор и открытие именно показанного места. Адаптивная вёрстка проверяется во viewport iframe шириной 390 и 320 CSS px. Это не проверка на физическом iPhone и не эмуляция Safari.

## Ограничения перед основным релизом

Остальные 27 карточек и все 15 маршрутов требуют редакционной проверки. У архивных маршрутов встречаются спорные остановки, дистанции и транспорт; они не представлены как проверенная навигация. Карта открывает поиск по названию, а не непроверенные GPS-координаты. Авторство и права на фото из исходной базы не подтверждены; для основного релиза необходим аудит. Нет подтверждённых событий, встреч и продавцов — коммерческие и социальные сценарии не имитируются.

Core Web Vitals и поведение на реальном Safari/iPhone в этой среде не измерялись. Предпросмотр предназначен для согласования и дальнейшего тестирования; слияние и замена основного сайта — после одобрения владельца.
