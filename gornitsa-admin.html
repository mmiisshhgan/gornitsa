Cloudinary для фото, главная страница, пароль.

☁️ Cloudinary — хранилище фотографий
Фото загружаются на Cloudinary и становятся доступны всем пользователям — на Android, iPhone, любом браузере. Бесплатный план: 25 ГБ, более чем достаточно.
⚠ Cloudinary не настроен — загрузка фото недоступна
Найдёте в Dashboard после регистрации
Settings → Upload → Add upload preset (Unsigned)
1
Зарегистрируйтесь бесплатно на cloudinary.com
2
Скопируйте Cloud Name из вашего Dashboard (например: my-gornitsa)
3
Перейдите в Settings → Upload, нажмите Add upload preset, выберите Unsigned, сохраните и скопируйте имя пресета
4
Вставьте Cloud Name и Upload Preset в поля выше и нажмите «Сохранить настройки Cloudinary»
